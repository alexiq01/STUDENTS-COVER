# مشروع غلاف جامعي

صفحة عربية لإنشاء غلاف بحث جامعي لجامعة تكريت، كلية العلوم، قسم الكيمياء.

## الملفات

- `index.html` — الصفحة، واجهة التحرير، معاينة الغلاف، وسلوك الطباعة.
- `assets/emblem-left.jpg` — شعار جامعة تكريت.
- `assets/emblem-right.jpg` — شعار كلية العلوم.

## الاستخدام

افتح `index.html` في متصفح حديث، ثم اكتب عنوان الموضوع وأسماء الطلاب، واختر اللقب العلمي وجنس المشرف. من زر الطباعة يمكن الطباعة مباشرة أو اختيار «حفظ بصيغة PDF».

## ملاحظة النشر على Netlify

شارة «Powered by Netlify» يضيفها Netlify تلقائيًا من خوادمه، لذلك لا تكون ضمن ملفات المشروع. لإخفائها عن الزوار، عطّلها من إعدادات المشروع: `Project configuration > General > Powered by Netlify badge`.
